### 第一批群系扩展

玄武岩三角洲之后依次进入：**末地 → 雪林 → 花开尖塔 → 哭嚎炼狱 → 平原**。每个新群系新增六张运行时 PNG：背景、墙面、墙边、地面、细长脆弱障碍及浮岛。

末地采用黑曜石柱、末地石浮岛和紫色虚空；雪林采用覆雪云杉、蓝色冰岩和远处雪雾；花开尖塔采用粉苔、淡黄色悬浮尖塔、紫色垂藤；哭嚎炼狱采用蓝紫草地、皂石链柱和巨型菌类。后两者以团队提供的 `花开尖塔样板/`、`哀嚎炼狱样板/` 为视觉参考，游戏名称按需求使用「花开尖塔」「哭嚎炼狱」。

新群系使用各自的生成配置。第一批新敌人的逻辑已接入：末地与花开尖塔有随墙生成的潜影贝，花开尖塔有开花史莱姆，哭嚎炼狱有地狱水母，雪林暂未配置独立敌人槽位。三种新敌人已接入正式像素 PNG、开壳状态和双帧动画；子弹也使用独立素材。音频控制器保持原样，新群系使用其默认音乐音色。

源图集位于 `assets/source/biome-expansion/`，由内置 ImageGen 生成，Sharp 仅用于裁切、缩放、透明度和调色板压缩。安装或配置 Sharp 后，可执行 `node tools/import-biomes.cjs` 重新导出，再执行 `node tools/pack-assets.cjs` 更新离线包。生成提示词见 [BIOME-PROMPTS.md](BIOME-PROMPTS.md)。

## 文件及尺寸

- `player_<blue|green|red>_<0|1>.png`：40 × 40 透明 PNG，0 为展翅上扬、1 为下拍；两帧保持头部和躯干位置，按 9 帧/秒循环。三种鹦鹉直接朝右绘制。`ArtAssets.playerScale = 0.8`，相对上一版 0.5 的宽高扩大 1.6 倍，实机显示框 51.2×51.2，玩家 18×16 碰撞框不变。菜单、选角、飞行与冲刺残影同步放大。

- `background_<biome>.png`：1024 × 256，128 色，左右镜像拼接保证循环接缝一致；采用 2 的幂尺寸，避免 Phaser TileSprite 内部插值。
- `wall_<biome>.png`、`wall_magma.png`：64 × 64，重新生成的手绘像素墙面，按原像素尺寸平铺，高墙不拉伸纹理。岩块层次、凹槽阴影和边缘高光与场景美术协调。
- `wallcap_<biome>.png`：64 × 8，与新墙面配套的边缘。
- `material_*.png`：32 × 32，供地面及素材库使用；墙体已使用新 `wall_*.png`。
- `vine_<biome>.png`：32 × 320，重新按约 1:10 的细长比例设计；小叶片／细石柱沿纵向排列，透明 PNG，方向向下。
- `island_<biome>.png`：80 × 40，透明 PNG，按原 120 × 60 显示。
- `bee*.png`、`bat*.png`、`phantom*.png`、`glow*.png`：40 × 32，双帧动画。
- `ghast.png`、`ghast_charge.png`、`ghast_fire.png`：64 × 64，待机／红眼张嘴／吐火三个状态。
- `enemy.png`：48 × 36，铁与铜、红石风格直升机。
- `stone.png`、`lava.png`、`fireball.png`、`bullet.png`：32 × 32，落石、熔岩、恶魂火球、荧光子弹。
- `emerald.png`、`life.png`：16 × 16，绿宝石与生命值拾取物。

PNG 透明度已量化为清晰边缘，游戏开启 `pixelArt` 和 `roundPixels`。碰撞尺寸取实体 `w/h`，不从 PNG 的透明轮廓推导碰撞。直升机与蝙蝠显示／碰撞尺寸均扩大为原来的 1.8 倍，分别为 **57.6 × 43.2** 和 **43.2 × 28.8**；蜜蜂和发光鱿鱼尺寸分别为 **70 × 50** 和 **68 × 60**。

幻翼从两侧可飞行区域高度的 28%–38% 处进场，朝玩家列的 56% 高度俯冲。冲刺速度使用屏幕坐标，不再被地图滚动抵消；从左右两侧均能到达场景中段，越过右边界也会正常回收。

## 接入位置

- `src/gfx/ArtAssets.js`：资源清单、材质映射、图片加载、循环动画、恶魂表情选择。
- `src/scenes/BootScene.js`：预加载 PNG，注册动画。
- `src/gfx/TextureFactory.js`：仅保留旧程序化素材作为参考，运行时不再调用。
- `WallEntity`：平铺材质及顶部／底部材质边缘。
- `VineEntity`、`FloaterEntity`：按群系选择 PNG。
- `GhastEntity`：发射前 0.55 秒蓄力表情、发射后 0.18 秒吐火表情；原发射计时与弹道不变。
- `BackgroundManager`：彩色 PNG 全景、地面及洞顶，无旧占位纹理染色。

## 运行与检查

直接双击根目录的 `index.html` 运行游戏，或双击 `art-preview.html` 查看素材。开发调试时可在项目根目录启动 HTTP 服务：

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

- [游戏](http://127.0.0.1:8080/index.html)
- [十群系美术预览](http://127.0.0.1:8080/art-preview.html)：可切群系、关闭滚动、显示碰撞框；通过「幻翼从左侧／右侧俯冲」按钮查看实际轨迹；展开「资源与行为验证」查看真实 Phaser 实例中的回归结果。
- `node tests/art-contract.cjs`：检查六群系资源覆盖、PNG 格式、尺寸、体积、重复 key 和恶魂视觉状态。
- `node --test tests/art-fixes.cjs`：检查放大尺寸、幻翼两侧进场、中段穿越、高速滚动及越界回收。

游戏运行时优先从 `assets/offline.js` 解码图片，避开 `file://` 下的 XHR 与跨域限制；Phaser 3.70.0 已保存在 `vendor/`。因此可以直接双击 `index.html` 离线运行。替换图片或音频后执行 `node tools/pack-assets.cjs` 更新离线包。

## 来源与再次生成

场景和敌人素材由 **内置 ImageGen** 生成，风格参考用户提供的 `assets/样板图片.png`，材质类型参考 [MC Assets 26.2](https://mcasset.cloud/26.2/)。三色鹦鹉飞行帧也由内置 ImageGen 制作，以团队提供的 `蓝鹦鹉.png`、`绿鹦鹉.png`、`红鹦鹉.png` 为配色与造型参考；已替换上一版的静态样板贴图。

完整提示词保存在 [PROMPTS.md](PROMPTS.md)。`tools/import-art.cjs` 用 Sharp 对生成图集切片、裁边、最近邻缩放、透明度及调色板压缩；这只是离线导出步骤，游戏不会运行它。重新导出时需安装 Sharp，并向脚本传入原始 ImageGen 图集目录（文件名见脚本）。正常修改游戏只需直接替换 `assets/art/` 中对应 PNG。

本轮墙面／细长障碍的源图已保存在 `assets/source/`。安装 Sharp 后运行 `node tools/refine-art.cjs` 即可从项目内源图重新导出，无需再次调用 AI；完整导出脚本也会在最后自动应用这轮修订。

鹦鹉重新导出：安装 Sharp 后运行 `node tools/import-parrots.cjs`，从 `assets/source/parrot_<color>_flight.png` 三张 512×256 双帧源图导出。固定单元切片保证两帧对齐。团队源样板保留在 `assets/`，不会被覆盖。

## 音频

音频来源仍是团队提供的文件，生成离线包时只做 base64 封装，不重新编码。背景音乐 `鹦鹉穿风.mp3` 约 4.96 MiB；6 个已接入音效文件合计约 147 KiB。

| 事件 | 文件 |
| --- | --- |
| 点击按钮或角色卡 | `样板音效/点击.mp3` |
| 成功发动冲刺 | `样板音效/dash.wav` |
| 实际扣血 | `样板音效/受伤.ogg` |
| 本局失败（一次） | `样板音效/失败.mp3` |
| 收集绿宝石 | `样板音效/收集绿宝石.mp3` |
| 冲刺击毁直升机 | `样板音效/man.mp3` |

`撞击.wav` 保留为样板，未接入。`man.mp3` 通过直升机实体类型和冲刺状态双重判定；其他怪物、障碍和反弹火球击杀不会触发。

音乐在首次用户操作后解锁，跨场景保持一首实例连续循环。平原明亮、海边清透、森林柔和、洞穴低沉、下界增强低频、玄武岩收敛高频；由 `AudioController.profiles` 中的低通／低频／高频／音量参数平滑过渡，不改变播放位置或速度。无 Web Audio 支持时保留原曲与群系音量变化。

`SettingsUI` 在主菜单提供两条独立音量滑块，并提供背景音乐、音效开关；四项偏好均保存到 localStorage。打开设置时暂停当前活动场景，关闭时只恢复由设置暂停的场景。切到后台暂停音乐与音效，返回后仅按已启用偏好恢复音乐。

测试：`node tests/audio-game.cjs`；浏览器可在 `art-preview.html` 的「音频试听」逐个播放音效，通过群系按钮切换音乐音色。

新敌人美术规格、动画与生成提示词见 [ENEMY-ART.md](ENEMY-ART.md)。
